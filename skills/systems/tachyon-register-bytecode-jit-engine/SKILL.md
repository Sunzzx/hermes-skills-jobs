# ➡ Tachyon: Register Bytecode Virtual Machine & Tracing JIT Engine

`tachyon-jit` is a production-grade register-based virtual machine featuring an industrial 3-address instruction set architecture (ISA), a control-flow graph (CFG) analyzer with dominator tree calculation, an AST/peephole bytecode optimizer, and a dynamic runtime tracing JIT compiler that synthesizes optimized execution paths.
